# Changelog

## 0.1.1 — 2026-10-17

- Show a two-second in-app notice after successful synchronization or manual position restoration.

## 0.1.0 — 2026-10-17

- Initial desktop release connecting Remember cursor position and Remotely Save.
- Per-device files and local device identities for multi-computer reading progress.
- Latest actual reading timestamp wins; manual resolution for equal-time conflicts.
- Pre-sync export, post-sync validation, local backups, and protection for reading during synchronization.
- Simplified Chinese settings, local export verification, and optional immediate restoration.
